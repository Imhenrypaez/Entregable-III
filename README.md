# Gestor de Tareas - Henry Paez v2.0

Proyecto de prueba en Python para demostrar la implementación de GitHub como herramienta de gestión de versiones.

## Funciones
- Ver tareas
- Agregar tareas
- Marcar tareas como completadas
- Eliminar tareas
- Guardar datos en archivo JSON

## Archivos
- `gestor_tareas.py`: programa principal
- `tareas.json`: archivo que almacena las tareas

## Cómo ejecutar
1. Instala Python.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta: `python gestor_tareas.py`
