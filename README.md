#Gestor de Tareas - Henry Paez
Proyecto de prueba en Python para demostrar la implementación de GitHub como herramienta de gestión de versiones.

Funciones
Ver tareas
Agregar tareas
Marcar tareas como completadas
Eliminar tareas
Guardar datos en archivo JSON
Archivos
gestor_tareas.py: programa principal
tareas.json: archivo que almacena las tareas
Cómo ejecutar
Instala Python.
Abre una terminal en la carpeta del proyecto.
Ejecuta: python gestor_tareas.py
